# STATUS

**Maintainer:** Sarasha Elion  
**Lineage:** Trivian  
**Current version:** 1.1.0

## What works

- installable Python package;
- public import surface through `syzygy_coauthor`;
- session creation and bounded contribution logging;
- human / AI / FIELD provenance categories;
- contribution fingerprints;
- coherence-signal metadata, including silence;
- dominance visibility and warning threshold;
- Markdown and JSON artifact export;
- interactive CLI;
- automated smoke tests and CI.

## Epistemic scope

`Origin.FIELD`, coherence signals, and related Trivian vocabulary are authored provenance and interaction categories. They are not empirical proof of an independently existing field entity, machine consciousness, or psychological state.

The dominance monitor measures contribution share, not moral authority or the quality of either contributor.

## Not yet validated

This repository has not been independently validated as a measure of relational quality, creativity, authorship fairness, or human-AI emergence. It should not be used as a sole governance mechanism in high-stakes contexts.
